# SEVENFOLD

**You are a mage holding the last rainbow.**

The Umbra drained the colour from the unicorns' world and sends its hollow herd against you: ash-black unicorns with burning horns in **seven colours**.

Match the rainbow to an enemy horn for **3x damage** and to charge **Nova**. Every hit you take removes one colour. Lose all seven and the run is over.

**Survive 10 waves, defeat 2 giants, and reach dawn.**

## Controls

### VR

| Control | Action |
| --- | --- |
| <kbd>Both Triggers</kbd> | **Arch** - block and strike |
| Swing + release | **Boomerang** |
| <kbd>One Trigger</kbd> + swing + release | **Lasso** |
| Flick loose rainbow | **Whip** |
| Arch + clap | **Nova** |
| <kbd>Both Grips</kbd> | **Sigil Mode** |
| Draw circle | Boomerang sigil |
| Cross hands, pull apart | Lasso sigil |
| Raise hands, slam | Nova sigil |

Hand tracking is supported; **pinch = trigger**.

### Desktop

| Key | Action |

| <kbd>Mouse</kbd> | Look |
| <kbd>Left Mouse</kbd> | Trigger |
| <kbd>B</kbd> | Arch |
| <kbd>Space</kbd> | Boomerang |
| <kbd>G</kbd> | Lasso |
| <kbd>N</kbd> | Nova |
| <kbd>V</kbd> | Sigil mode |
| <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> / <kbd>Q</kbd><kbd>E</kbd> | Move hands |
| <kbd>R</kbd> | Restart |
| <kbd>M</kbd> | Mute |

## Seven Colours. Seven Lives.

Your rainbow runs from **red on the left to violet on the right**. Matching colour hits deal **3x damage** and charge Nova. Defeating a giant restores **2 colours**.

## The Horde Is the Music

Every unicorn sings its colour as a positional voice. The number, colour and position of enemies dynamically shape the soundtrack around you.

**Seven colours. Seven lives. One dawn.**
